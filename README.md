## 🌟 نبذة عن المشروع / Project Overview

**واسطتك (WASTATAK)** هي منصة تقنية متكاملة لإثبات الكفاءة وتسهيل التوظيف في أسواق مصر، الخليج العربي، والشرق الأوسط.
تقوم المنصة باستبدال السير الذاتية والاختبارات النظرية بـ **مشروعات عملية واقعية تحاكي أول 90 يوماً في الوظيفة**، وتقدم تقارير أدلة ملموسة مدعومة بالذكاء الاصطناعي إلى جانب مستشارين وخبراء بشريين معتمدين.

---

## 💎 المزايا الرئيسية للمشروع / Key Features

1. **وسام إثبات الكفاءة الرقمي 3D (Spatial Three.js Emblem):**
   * مجسم ثلاثي الأبعاد هندسي عاكس (Prismatic Crystal) مع قلب ذهبي دوار وحلقات تيتانيوم جيروسكوبية بتفاعل فيزيائي 60 FPS.
2. **الركائز الأربع المتكاملة (The 4 Core Pillars):**
   * الملف المهني الرقمي القابل لإعادة الاستخدام.
   * إثبات القدرة العملية عبر محاكاة الوظائف (أول 90 يوماً).
   * التحليل والتقييم بالذكاء الاصطناعي متعدد الأبعاد.
   * حلقة المعايرة والتحسين المستمر بعد التعيين.
3. **فريق المستشارين والخبراء البشريين (Real Human Advisors):**
   * مستشارون حقيقيون متخصصون في الهندسة السحابية، الموارد البشرية، والقيادة التنفيذية.
   * نظام تفاعلي لحجز جلسات الاستشارة للشركات والمرشحين.
4. **حاسبة الوفر الاقتصادي للشركات (Interactive ROI Calculator):**
   * احتساب مباشر لتكاليف التوظيف التقليدي المهدرة وأيام العمل الموفرة للفريق.
5. **كتالوج المحاكاة الواقعية (Simulations Catalog):**
   * تحديات حية في هندسة البرمجيات، تحليل البيانات، تصميم UI/UX، والأمن السيبراني.
6. **فريق موظفي الذكاء الاصطناعي التفاعلي (AI Workforce Chat):**
   * شات تفاعلي مباشر مع الوكلاء الأذكياء (سارة، كريم، نور، وفهد).
7. **بنك الكفاءات الأعمى (Blind Screening Talent Pool):**
   * فحص نزيه يقضي على المحسوبية بالتركيز على الأدلة وكود الإنجاز فقط.
8. **العرض الاستثماري للجنة التحكيم (Shark Tank Pitch Deck):**
   * شرائح عرض تنفيذية تشرح المشكلة، الحل، نموذج العمل (Business Model)، وحجم السوق ($38B).
9. **دعم ثنائي اللغة (Arabic RTL & English LTR):**
   * تبديل فوري بنقرة زر واحدة.

## 🚀 كيفية التشغيل والرفع على GitHub / Quick Run & Deployment

### 1. للتشغيل الفوري محلياً:
* اضغط مرتين على ملف **`index.html`** أو **`تشغيل_الموقع.bat`** وسيعمل فوراً في أي متصفح بدون إنترنت وبدون أي سيرفر!

### 2. لنشر الموقع مجاناً عبر GitHub Pages:
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub باسم `wastatak-3d`.
2. ارفع ملفات هذا المجلد إلى المستودع.
3. اذهب إلى **Settings** > **Pages** > اختر الفرع **main** أو **master** والمجلد `/ (root)` ثم اضغط **Save**.
4. سيصبح موقعك متاحاً أونلاين على الرابط: `https://<your-username>.github.io/wastatak-3d/`
